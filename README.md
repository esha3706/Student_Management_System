# 🎓 Student_Management_System

A desktop-based **Student_Management_System** developed using **Python,GUI,Tkinter,and SQLite3**. This project provides a simple and user-friendly graphical interface to manage student records efficiently.
This project was developed as a practical project to strengthen my understanding of *Python programming, GUI development, database management, CRUD operations, and application development*.

## 📌 Project Overview

The Student_Management_System is designed to perform basic student record management operations through a graphical user interface (GUI).
It allows users to securely log in and perform various operations such as adding, viewing, updating, deleting, and searching student information.

## ✨ Features

* 🔐 Login Authentication
* 📊 Dashboard Interface
* ➕ Add Student Records
* 💾 Save Student Information
* 👀 View Student Records
* ✏️ Update Student Information
* 🗑️ Delete Student Records
* 🔍 Search Student Records
* ✅ Input Validation
* 💬 Message Box Notifications
* 🗄️ SQLite3 Database Integration
* 🖥️ User-Friendly Tkinter GUI
* 🚪 Logout Functionality
